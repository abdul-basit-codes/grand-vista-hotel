# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-22

### Added
- 100-room hotel front desk system
- Room directory with 5 categories (Single, Double, Family, Elite, Meeting)
- Guest check-in/check-out with receipts
- Restaurant ordering with room charges
- Revenue tracking and occupancy statistics
- Cloud sync with localStorage fallback
- Vercel serverless API backend
